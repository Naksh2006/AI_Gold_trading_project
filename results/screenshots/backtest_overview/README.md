# Backtest Overview & Strategy Performance Screenshots

This directory stores visual verification screenshots from TradingView Strategy Tester and simulated equity curves for the **AI Gold Quantitative Strategy** (`AI_Gold_Quant_Strategy.pine`).

### Recommended Screenshots to Place Here:
1. `tradingview_strategy_tester.png`
   - Capture of the TradingView Strategy Tester tab showing Net Profit, Total Closed Trades, Percent Profitable, Profit Factor, and Max Drawdown.
2. `equity_curve.png`
   - Capture of the Performance Summary chart showing the cumulative equity curve vs Buy & Hold benchmark.
3. `drawdown_chart.png`
   - Underwater drawdown equity curve highlighting strict downside containment (< 0.50% max DD on test window).
4. `trade_list_sample.png`
   - First 10–15 executed trades in TradingView with Entry, Exit, Signal Name, and Profit/Loss.
